## Architecture (live · refreshed 2026-06-25)

**Team body-composition tracker + activity manager** for a ~12-person IT squad (Aumovio Sibiu). Log weight / body-fat / muscle / water / visceral + measurements; gamified (XP, tiers, streaks); social (reactions + comments + @mentions); book free **Aria** gym sessions (Aumovio partnership). Romanian UI.

**Stack:** Next.js 15 (App Router) · React 18 · TypeScript · Tailwind 3 · lucide-react · `@upstash/redis` (social + bookings) · Google Sheets via Apps Script. Deployed on **Vercel** (push to `main` → auto-deploy).

**Entry points / routes**
- `app/page.tsx` — main dashboard = the **logged-in user's** data (PersonalMetrics + PersonalHistory)
- `app/activitati/page.tsx` — **Aria weekly calendar** (book/unbook sessions, see who's going)
- `app/log/page.tsx` — **admin-only** measurement logging (password `vinclu-823`; non-admins blocked)
- `app/api/data` — Sheets read proxy (`force-dynamic`) · `app/api/submit` — Sheets **write** proxy · `app/api/activities` — Upstash bookings · `app/api/social/{likes,comments}` — Upstash · `app/api/health` — version + KV-env check

**Key files**
- `lib/shape.ts` — domain source of truth (types, Person/Entry, XP/tiers/colors, `ADMIN_NAMES`, `submitEntry` → `/api/submit`)
- `lib/activities.ts` — Aria schedule (7 sessions) + week/date helpers · `lib/activities-store.ts` — Upstash hash `activities:bookings` · `lib/useActivities.ts` — optimistic + 30s poll + **localStorage fallback**
- `components/activities/WeeklyCalendar.tsx` — 5-col day grid, capacity bars, avatar chips, "Mă duc 💪" toggle
- `components/ui/AriaLogo.tsx` — real Aria circular mark (`public/aria-icon.png`, cropped from ariasibiu.ro)
- `components/AppShell.tsx` — layout: TopBar + **left SquadRail** (now with Aria section) + main + **PeekModal**
- `components/dashboard/PeekModal.tsx` — blurred overlay: click colleague → their data + reactions/comments
- `components/dashboard/MetricDetailDrawer.tsx` — per-metric deep-dive; **fixed 62vh in peek**, internal-scroll history
- `lib/social.tsx` + `lib/social-store.ts` — `useSocial` (optimistic + 30s poll + localStorage fallback) on Upstash

**Data flow:** `useShapeData` → `/api/data` → Apps Script → `Person[]`. Writes: `submitEntry` → `/api/submit` (server POST, `redirect:'follow'`) → Apps Script `doPost`. Social → `/api/social/*` keyed `${date}_${name}`. Bookings → `/api/activities` keyed `${activityId}:${date}`. Identity decoupled: `loggedInUser` (you) vs peek target (who you view).

**Conventions / gotchas**
- masterpiece-ui language (slate-950 + indigo, `--color-*` vars) — intentionally **diverged**: left rail + peek modal.
- **Don't run `next build` while `next dev` runs** — shared `.next` → live dev page renders unstyled.
- **Vercel KV creds are "sensitive"** → `vercel env pull` returns them **empty** locally. Social + bookings fall back to localStorage in dev; prod has real KV (shared state). Verify via `GET /api/activities` → 200 (not 503).
- Verify a deploy with `GET /api/health` (commit SHA + KV env). Prod: <https://shapesquad.vercel.app>.
